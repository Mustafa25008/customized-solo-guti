# 🎮 Game Project

A browser based game built with **React, TypeScript, and Tailwind CSS v4**. The project uses Vite for fast development and a modern frontend development workflow.

## ✨ Features

- **Interactive Gameplay:** Play directly in your browser.
- **React:** Component based UI development.
- **TypeScript:** Type safety and improved code maintainability.
- **Tailwind CSS v4:** Modern styling and responsive layouts.
- **Vite:** Fast development server and optimized builds.

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript
- **Styling:** Tailwind CSS v4
- **Build Tool:** Vite
- **Package Manager:** npm

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed on your machine.

### 1. Clone the Repository

Replace `your-repo-name` with your actual GitHub repository name.

```bash
git clone https://github.com/Mustafa25008/your-repo-name.git
```

### 2. Navigate to the Project Directory

```bash
cd your-repo-name
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Game

Open the local URL displayed in your terminal, usually [http://localhost:5173](http://localhost:5173), in your browser.

## 🏗️ Build for Production

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```
